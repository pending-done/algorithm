### 문제 설명

어느 학교에 페인트로 칠해진 긴 벽이 있습니다. 벽의 여러 섹션 중 일부가 지저분해져 페인트를 덧칠하기로 했습니다.

페인트를 칠할 롤러의 길이는 m이며, 롤러로 벽을 한 번 문지르면 롤러의 길이만큼 벽을 칠할 수 있습니다. 롤러를 다시 문지르기 전까지 롤러에 페인트가 묻어있다고 가정합니다.

벽의 길이 n, 롤러의 길이 m, 칠해야 할 구역의 번호가 담긴 정수 리스트 section이 매개변수로 주어질 때, 롤러로 페인트칠해야 하는 최솟값을 return 하는 solution 함수를 완성해주세요.

---

#### 제한사항

- 1 ≤ m ≤ n ≤ 100,000
- 1 ≤ section의 길이 ≤ n
- 1 ≤ section의 원소 ≤ n
- section의 원소는 오름차순으로 정렬되어 있습니다.
- section에 중복된 원소는 없습니다.

---

#### 입출력 예

| n | m | section   | result |
| - | - | --------- | ------ |
| 8 | 4 | [2, 3, 6] | 2      |
| 5 | 4 | [1, 3]    | 1      |
| 4 | 1 | [1, 2, 3, 4] | 4   |
